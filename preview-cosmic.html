CASE STUDY // 01 · MULTI-AGENT PIPELINE ● PRODUCTION AUDITOR LIVE

AgentAudit — Autonomous AI Security Scanner

Automated Solidity & GitHub Pull Request Vulnerability Audit Suite

agentaudit-gamma.vercel.app — Autonomous Security Dashboard

The Challenge: Smart contract verification is prohibitively slow and expensive. Independent developers and hackathon hackers frequently deploy contracts plagued with reentrancy vulnerabilities and faulty access controls because automated, zero-friction verification did not exist.

The Architectural Solution: Constructed a parallelized multi-agent audit pipeline using Python asyncio and Groq Llama-3. Four specialized agents coordinate simultaneously: a Guard for zero-day vulnerabilities, a Speedster for gas bottlenecks, a Solidity Agent for reentrancy analysis, and an automated Fixer that outputs git-ready patch diffs.

CASE STUDY // 02 · LOCAL-FIRST ARCHITECTURE ● 100% CLIENT-SIDE PARSING

UPI Ledger — Offline PDF Financial Analytics

Zero-Cloud In-Browser Statement Extractor with IndexedDB Persistence

killer13b.github.io/upi-ledger — Client-Side Financial Parser

The Challenge: Bank and UPI statement PDFs contain sensitive financial telemetry. Most budgeting tools force users to upload PDFs to remote servers, exposing private transactions to breach risks.

The Architectural Solution: Engineered a 100% offline-first parsing engine running completely inside the browser client. Utilizes pdf.js worker threads to parse password-protected statement tables locally. Employs Dexie (IndexedDB) for encrypted local storage and fast relational analytics with zero external API calls.
