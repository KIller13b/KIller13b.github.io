AgentAudit — Multi-Agent Security Engine

SYSTEM CASE STUDY // 01
● LIVE PRODUCTION AUDITOR

Autonomous Multi-Agent AI Security Scanner for Solidity & GitHub PRs

Role: Full-Stack & Agent Architecture Stack: FastAPI · React 18 · Solidity · Groq Llama-3 Timeline: 2026
agentaudit-gamma.vercel.app — Audit Dashboard

The Challenge

Manual smart contract security audits take days and cost thousands of dollars. Indie Web3 developers and hackathon builders ship contracts with reentrancy bugs, broken access controls, and risky selfdestruct operations simply because rapid automated verification tools don't exist.

The Engineering Solution

Engineered an autonomous multi-agent pipeline using Python asyncio. Four specialized agents audit the codebase in parallel: a Guard for zero-day vulnerabilities, a Speedster for gas bottlenecks, a Solidity Agent for Web3 reentrancy, and a Fixer that outputs git-ready patch diffs.

[Case Study 02 // Local-First]

UPI Ledger — 100% Client-Side Financial Parser

SYSTEM CASE STUDY // 02
● ZERO-SERVER PRIVACY

Client-Side PDF Statement Parser & Expense Analytics Engine

Role: Frontend Systems & Local Persistence Stack: React 18 · TypeScript · pdf.js · Dexie · Tailwind v4 Timeline: 2026
killer13b.github.io/upi-ledger — In-Browser Parsing

The Challenge

Bank and UPI statements contain deeply private financial data. Nearly every existing budgeting app demands that users upload PDFs to external servers, creating privacy risks and vulnerability to data breaches.

The Engineering Solution

Constructed an offline-first parsing engine running completely inside the user's browser tab. pdf.js worker threads extract encrypted PDF transaction tables, while Dexie (IndexedDB) manages queries and charts locally. The app functions identically with Wi-Fi disabled.

0 Bytes Transmitted to Cloud
100% Offline Capable
IndexedDB Hardware Encrypted Storage
