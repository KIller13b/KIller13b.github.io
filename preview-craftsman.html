How I Approach Software
  • Privacy by architecture: Don't collect data you don't need, and run computation on the user's device whenever possible instead of sending sensitive files to an API.
  • Ship working software: I care more about building tools that actually solve an annoyance than writing abstract boilerplate or chasing trends.
  • Keep runtimes lean: If a tool can run with zero server dependencies or purely in WebGPU / WASM, it's cheaper to maintain and indefinitely resilient.
