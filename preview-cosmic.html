CASE STUDY 01 // PARALLEL AI SECURITY ● PRODUCTION AUDITOR LIVE

AgentAudit — Multi-Agent Security Engine

Autonomous Solidity & GitHub Pull Request Vulnerability Audit Pipeline

agentaudit-gamma.vercel.app — Autonomous Security Dashboard

The Problem: Manual smart contract audits take days and cost thousands of dollars. Independent developers and hackathon builders ship contracts with reentrancy bugs and risky selfdestruct operations simply because rapid automated verification does not exist.

The Engineering Solution: Architected an asynchronous multi-agent pipeline using Python asyncio and Groq Llama-3. Four specialized agents coordinate in parallel: a Guard for zero-day vulnerabilities, a Speedster for gas bottlenecks, a Solidity Agent for reentrancy analysis, and an automated Fixer that produces git-ready patch diffs.

CASE STUDY 02 // ZERO-SERVER PRIVACY ● 100% CLIENT-SIDE PARSER

UPI Ledger — Offline PDF Financial Analytics

Zero-Cloud In-Browser Statement Extractor with IndexedDB Persistence

killer13b.github.io/upi-ledger — Client-Side Statement Parser

The Problem: Bank and UPI statement PDFs contain deeply sensitive personal financial telemetry. Virtually all budgeting apps force users to upload PDFs to external cloud servers, exposing private records to server breaches.

The Engineering Solution: Built an offline-first parsing engine running completely inside the browser sandbox. pdf.js worker threads extract encrypted transaction tables locally without blocking UI rendering, while Dexie (IndexedDB) manages encrypted relational queries with zero external telemetry.

Cloud Egress 0 Bytes
Network Requirement 100% Offline
Storage Engine Dexie (IndexedDB)
